# ocr-scanned-text-extraction-challenges
This example demonstrates how Optical Character Recognition (OCR) extracts text from an image, simulating a scanned PDF bank statement. It highlights the capabilities and common challenges of OCR, such as misinterpreting similar-looking characters (e.g., '1' vs 'l', '0' vs 'O', '5' vs 'S') and handling special characters.
